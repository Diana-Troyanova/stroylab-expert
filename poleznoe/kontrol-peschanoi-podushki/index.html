Как проверить уплотнение песчаной подушки

Какие значения взять из протокола и с чем сравнить результат для конкретного слоя.

Какие данные взять из протоколов

Для выбранной точки нужны фактическая плотность сухого грунта в слое и максимальная плотность сухого грунта для того же материала. Проверьте единицы и обозначение слоя. Плотность грунта при естественной влажности нельзя напрямую подставить вместо сухой плотности.

Как сравнить результат с проектом

Разделите фактическую сухую плотность на максимальную. В учебном примере 1,54 / 1,68 ≈ 0,917. Если проект требует не менее 0,95, значение для этой точки ниже порога. Требование для своего участка берут из проекта.

Почему важна отметка слоя

Измерение на верхнем горизонте характеризует материал в месте измерения. Чтобы проследить результаты по толщине подушки, свяжите каждый протокол с участком на плане, отметкой и этапом отсыпки. При смене песка проверьте, к какой пробе относится лабораторный максимум.

Лабораторный метод определения максимальной плотности и область его применения описаны в ГОСТ 22733-2016.
