# СТРОЙЛАБЭКСПЕРТ — сайт строительной лаборатории

Многостраничный сайт с каталогом услуг, инженерным справочником и калькуляторами для специалистов строительной отрасли. Проект находится в разработке и представлен как работа для портфолио.

## Возможности

- Страницы направлений испытаний строительных материалов.
- Справочник ПТО: статьи, расчёты и бланки документов.
- Калькуляторы коэффициента уплотнения грунта, массы и длины арматуры, объёма бетона и количества контрольных кубов по заданным параметрам.
- Перевод давления из МПа в кгс/см². Класс бетона по одному значению прочности не определяется.
- Региональные страницы и выбор города.
- Адаптивная вёрстка, мобильное меню, управление меню с клавиатуры.
- Интерактивная SVG-схема слоёв фундаментной плиты с переходами к услугам и расчётам.

## Технологии

**HTML5 · CSS3 · JavaScript · SVG · Python**

Страницы написаны на HTML, стили и логика калькуляторов вынесены в общие файлы. JavaScript работает в браузере без фреймворков. Python используется для локального просмотра и генерации региональных версий; серверная часть для работы сайта не требуется.

## Локальный запуск

Нужен установленный Python 3.

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте его с помощью Git.
2. Откройте терминал в папке, где находится `index.html`.
3. Запустите сервер:

   ```bash
   python -m http.server 8000 --bind 127.0.0.1
   ```

   В Windows вместо `python` можно использовать `py`, если установлен Python Launcher.

4. Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

Остановка сервера — `Ctrl+C`. Страницы используют пути от корня сайта, поэтому для просмотра нужен локальный HTTP-сервер.
